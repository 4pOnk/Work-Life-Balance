# Work Life Balance 0.4

## Установка и обновление

Поставка рассчитана на Windows x64. .NET, Node.js и dev-сервер устанавливать не нужно: runtime и интерфейс включены в папку приложения. Архив распаковывается целиком; один EXE отдельно переносить нельзя.

1. Закройте трекер через трей и закройте Firefox, чтобы освободить Native Messaging-помощник.
2. Из распакованной новой поставки выполните в обычной Windows PowerShell `powershell -ExecutionPolicy Bypass -File .\install.ps1 -Launch`. Права администратора не требуются. Скрипт устанавливает файлы в `%LOCALAPPDATA%\Programs\WorkLifeBalance`, создаёт ярлык меню «Пуск» и регистрирует помощник Firefox для текущего пользователя.
3. Для первой установки расширения откройте Firefox → Дополнения → шестерёнка → «Установить дополнение из файла» и выберите `firefox-extension-signed.xpi`. Уже установленное подписанное расширение 0.2.0 переустанавливать не требуется. Неподписанный ZIP предназначен только для разработки.
4. Откройте статистику из трея. Основной адрес `http://127.0.0.1:47831`; при смене порта адрес меняется.

Не запускайте установщик из изолированной среды агента: её реестр может быть невидим обычному Firefox. Если PowerShell ограничен политиками организации, не обходите их; используйте разрешённый администратором способ запуска.

Обновление выполняется тем же скриптом поверх существующей установки. История и настройки находятся отдельно, в `%LOCALAPPDATA%\WorkLifeBalance`; установщик их не удаляет. Перед обновлением рекомендуется создать копию через интерфейс. Приложение не проверяет обновления через сеть. Windows может предупреждать о неподписанном EXE/PowerShell-скрипте: Authenticode-подписи издателя у этой локальной сборки нет.

## Управление

- Значок трея: статистика, настройки, AFK, пауза и полный выход. Закрытие веб-вкладки не останавливает сбор.
- `Win + Shift + N`: ручной AFK/возврат. При занятом сочетании задайте другое в настройках. Хоткей действует только при запущенном трекере.
- Авто-AFK переносит время с последнего ввода в отсутствие после достижения порога. По умолчанию 30 минут; для длинного видео увеличьте порог или отключите авто-AFK.
- Активное окно Firefox по умолчанию считается отдыхом. В разделе «Рабочие сайты» можно добавить домен либо вставить HTTP/HTTPS-ссылку: сохраняется только домен. Он и его поддомены будут автоматически считаться работой с момента добавления. Удаление правила влияет только на новые посещения. Приватная/неизвестная вкладка остаётся отдыхом. AFK и ручные исправления приоритетнее правил сайтов. Историю по-прежнему можно исправить вручную, разделить интервал и отменить исправление.
- Календарь отображает секунды/минуты для короткой работы: `9 с` не превращается в `0.0 ч`. Настоящий ноль нейтральный.
- «Данные и запуск» → автозапуск регистрирует запуск при входе текущего пользователя в Windows. Переключатель показывает наличие точной записи Run для этой установки. Windows может дополнительно отключить её в «Автозагрузке» диспетчера задач; это ограничение ОС.

## Дела и рекап

«Дела» находятся между статистикой и календарём. Добавьте название и вес 1–5; вес означает трудозатратность и меняет цвет задачи. Сегодня можно изменять, удалять, выполнять и отменять выполнение задач. Выполненные остаются в том же списке. Для переноса вручную откройте редактирование и выберите дату; с выполненной задачи сначала снимите отметку.

Выберите будущую дату в списке или календаре для планирования. Отметка выполнения доступна только начиная с запланированного дня. Незавершённое автоматически появляется сегодня, даже после нескольких дней без запуска. При выборе прошлого дня отображаются только завершённые в тот день задачи без возможности редактирования. Дата выполнения сохраняется и не меняется при смене часового пояса.

Левая половина календарного квадрата показывает часы работы, правая — сумму весов выполненного. Синяя шкала фиксирована: 0, 1–4, 5–9, 10–14, 15+. Вес никак не добавляет часы. На узком экране длительность сокращена до целых секунд/минут/часов; точное значение есть в подсказке и статистике выбранного дня.

## Экспорт, копии и срок хранения

Экспорт CSV/JSON содержит итоговые интервалы и выполненные задачи за выбранные календарные дни (включительно, не более 366 дней за раз), с учётом ручных правок. В JSON задачи находятся в `completedTodos`; в CSV — строки `Todo` с нулевой длительностью, названием, `task_weight` и `task_id`. Границы интервалов в UTC, часовой пояс и даты отчёта указаны в JSON. Паузы отделены от активности. Это отчёт, а не формат полного восстановления; открытые планы, источник и обратимые правки сохраняются в SQLite-копии. CSV экранирует формулы и кавычки.

Кнопка «Создать копию» сохраняет согласованный SQLite-снимок в `%LOCALAPPDATA%\WorkLifeBalance\backups`. Можно скопировать закрытый `.db` из этого каталога на свой локальный диск. Не копируйте работающий `activity.db` отдельно от WAL: используйте кнопку копирования.

Для восстановления приостановите учёт, выберите копию и введите `ВОССТАНОВИТЬ`. Восстанавливается **история целиком**, включая исходные наблюдения, AFK, паузы, правила пересчёта и ручные правки. Текущие настройки порта, хоткея, процессов и срока хранения сохраняются. Перед заменой автоматически создаётся страховочная копия. Затем самостоятельно возобновите учёт.

Внешнюю ранее созданную копию можно вернуть в папку `backups` под исходным именем из 32 hex-символов с расширением `.db`, затем обновить страницу. Поддерживаются копии схемы v3 и v4. Копия v4 заменяет также все задачи; старая v3 восстанавливает только историю времени и сохраняет текущие задачи. Повреждённые копии, копии из будущего и несовместимые версии не заменяют текущие данные. Перед переходом на v4 сохраняется `activity.db.before-v4.bak`. Если основная БД повреждена и приложение не запускается: завершите его и Firefox, сохраните весь каталог данных отдельно, переместите повреждённые `activity.db`, `activity.db-wal`, `activity.db-shm` в отдельный каталог и поместите проверенную копию как `activity.db`. Не смешивайте старый WAL с восстановленной базой.

Срок хранения `0` означает без ограничения. Положительное значение сохраняет предпочтение для кнопки «Очистить по сроку»: остаются последние N календарных дней, включая сегодня. **Фонового удаления нет.** Очистка требует паузы, показывает конкретный диапазон и подтверждается словом `УДАЛИТЬ`. Есть удаление выбранных дней и всей истории. Интервалы на границах обрезаются; история снаружи диапазона и приоритет ручных правок сохраняются.

Копии автоматически не удаляются и могут содержать уже удалённую историю. Управляйте ими в локальной папке `backups`, а миграционными копиями `*.before-v*.bak` в каталоге данных. Экспорты также остаются там, куда вы их скачали. Удаление в интерфейсе не является гарантированным физическим стиранием данных с SSD или из резервных копий ОС.

## Удаление

Удаление истории и очистка по сроку включают выполненные задачи соответствующего диапазона по моменту выполнения. Открытые задачи и планы не удаляются; их можно удалить по отдельности в списке «Дела».

Закройте трекер и Firefox, запустите `uninstall.ps1` из установленной папки. По умолчанию история, копии и настройки остаются. `uninstall.ps1 -DeleteData` дополнительно спрашивает слово `DELETE` и только после этого удаляет весь стандартный каталог данных. Экспорты в других папках, внешние копии и тестовые `--data-dir` не затрагиваются. Расширение удаляется отдельно в Firefox.

## Если что-то не работает

- Занят порт: учёт продолжается; измените порт через трей и перезапустите. Не завершайте чужие процессы.
- Нет связи с Firefox: убедитесь, что трекер запущен; запустите установщик/регистрацию из обычной PowerShell. Без расширения Firefox продолжает учитываться как отдых с неизвестной вкладкой.
- Повреждённая/недоступная база: программа не пересоздаёт её молча. Локальные ошибки: `%LOCALAPPDATA%\WorkLifeBalance\errors.log` (ротация, без URL/заголовков/текстов исключений).
- Уведомления могут скрываться Windows или режимом «Не беспокоить». Состояние доступно в трее и интерфейсе.
- Приложение не посылает историю в сеть. Сборка зависимостей и подпись расширения — отдельные сетевые действия разработчика, не работа установленного продукта.
