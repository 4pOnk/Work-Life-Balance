# Итерация 2

## Реализовано

- Firefox WebExtension, локальный Native Messaging мост, heartbeat, проверка свежести и последовательности сообщений, привязка к foreground HWND, сброс устаревших метаданных и экран подключения.
- URL/домен/заголовок активной вкладки с удалением userinfo/query/fragment, выбором детализации и исключением приватных окон.
- Рабочие executable: список процессов с группировкой, ручной ввод, добавление/удаление, применение к будущему либо существующей истории. Firefox остаётся отдыхом по умолчанию.
- SQLite v2: отдельные исходные наблюдения, AFK, снимки пересчитанных правил и обратимые ручные поправки. Перед миграцией v1 создаётся резервная копия.
- Дневная лента, список интервалов и источник категории, массовое изменение, правка части интервала и отмена всего действия. Пробелы не превращаются в начисленное время.

Приоритет: последняя действующая ручная правка → AFK → Firefox как отдых → исторический пересчёт правил → исходная категория. Отмена последней правки вновь открывает предыдущую; оригинальные наблюдения не стираются.

## Проверки

- 49 .NET unit/integration/native тестов: 42 логика/хранилище/протокол + 7 Windows.
- 6 тестов сборщика Firefox: активная вкладка, приватность, смена фокуса во время запроса, ограничение URL.
- `web-ext lint`: 0 ошибок, предупреждений и notices.
- 4 Playwright-сценария на настоящем backend с синтетической тестовой базой: настройки/AFK, безопасность HTTP, частичные и массовые правки, перезагрузка, отмена и приоритет после пересчёта правил. Проверены desktop/mobile снимки.
- NativeHost → named pipe → координатор → SQLite: реальный бинарный мост с подставным foreground-источником, очистка URL, повтор сообщения, потеря фокуса и отключение.
- Настоящий Firefox с временным headless-профилем: дополнение успешно подключилось через зарегистрированный NativeHost к тестовому трекеру. Обычный профиль не менялся.

Основная проверка: `./scripts/test.ps1`. UI: инструкции в README; никогда не запускать изменяющие UI-тесты на личной базе. Дополнительная проверка моста:

```powershell
dotnet run --project tools/WorkLifeBalance.Smoke -- --browser ".artifacts/app/WorkLifeBalance.NativeHost.exe" ".local/native-browser-smoke-new"
```

## Границы

Постоянная установка Firefox требует подписанного Mozilla XPI; путь документирован в [firefox.md](firefox.md), но неподписанный архив не выдаётся за постоянную установку. Код и пользовательская история никуда не отправлялись. Ручной прогон видимых нескольких окон Firefox и приватного окна остаётся проверкой перед окончательной поставкой; соответствующие переходы покрыты автоматическими тестами.

Одновременно поддерживается один профиль Firefox. Точность наблюдений ограничена опросом, не миллисекундами. Календарь и полные графики относятся к итерации 3; self-contained поставка, автозапуск и экспорт — к итерации 4.
