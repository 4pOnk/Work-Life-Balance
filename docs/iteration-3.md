# Итерация 3: dashboard и календарь

Реализованы месячный календарь, фиксированная шкала абсолютных рабочих часов (0, до 1, 1–4, 4–8, 8+), подсказки по наведению/фокусу, выбор дня, переход между месяцами, месячные и недельные суммы. Недельные строки ограничены выбранным месяцем, поэтому их сумма равна итогу месяца. Будущее, отсутствие данных и записанный день без работы различаются цветом и символами.

Дневной отчёт содержит почасовой график Recharts, доступную таблицу значений, разбивку по приложениям, долю работы, длительность пауз, неизвестных пробелов, будущую часть дня и предварительный период до авто-AFK. Исходные интервалы и правки обрабатываются прежним серверным классификатором; интерфейс не пересчитывает категории. Изменения правил и истории обновляют графики без перезагрузки.

`GET /api/v1/dashboard?date=yyyy-MM-dd&month=yyyy-MM` возвращает дневные и месячные проекции под одной блокировкой координатора. Календарь читает максимум 31 день, без передачи месячной истории вкладок в frontend. Почасовые корзины строятся по UTC внутри границ локального дня; повторный час при осеннем DST сохраняется отдельной строкой с UTC-смещением. Часовой пояс пока системный, его имя отображается в дневном отчёте.

SQLite v3 добавляет таблицу `pauses` без изменения исходных наблюдений. Смежные подтверждённые паузы объединяются. Неизвестные разрывы коллектора не приписываются паузе; известный сон/блокировка во время паузы остаётся паузой. Старые пробелы до v3 сохраняются неизвестными. Миграция добавочная, без удаления данных.

## Проверки

- 60 .NET-тестов: 53 domain/application/storage и 7 Windows. Новые проверки: дни по 23/25 часов, месяц и недели, правки поверх AFK, отмена, сохранение пауз, неизвестное/будущее/предварительное время и границы шкалы.
- 6 Playwright-сценариев на отдельной базе: прежние настройки/безопасность/история, согласованность dashboard, календарная навигация, пустой день, валидация дат, desktop/mobile. Снимки проверены визуально; переполнение мобильной панели месяца исправлено.
- ESLint, Prettier, TypeScript и production build; npm audit production-зависимостей: 0 уязвимостей.
- Recharts 3.10.1 и react-is 19.1.1 зафиксированы. [Совместимость react-is с React](https://github.com/recharts/recharts/blob/main/README.md). Библиотеки поставляются локально, без CDN. Vite сообщает о размере основного JS chunk около 598 КБ (179 КБ gzip); это предупреждение размера, не ошибка сборки.

## Воспроизведение

```powershell
./scripts/test.ps1
dotnet run --project tools/WorkLifeBalance.Smoke -- --seed ".local/iteration3-new" 47833
# Запустить собранный Host с --data-dir, указывающим на этот новый каталог.
cd src/web
$env:WLB_TEST_URL='http://127.0.0.1:47833'
npm run test:e2e
```

Для проверки использовались `.artifacts/iteration3-test` и `.local/iteration3-ui`, не личная история. Не запускать изменяющие E2E-тесты на пользовательской базе. Полная поставка, автозапуск, экспорт и управление хранением остаются в итерации 4. Подписанный Firefox XPI не изменён и повторной подписи не требует.
