Обновление применено к личному экземпляру после резервного копирования; настройки сохранены, ошибок учёта и регистрации хоткея нет, Firefox снова подключён. ## Проверки

```powershell
. ./scripts/dotnet.ps1
& $Dotnet test tests/WorkLifeBalance.Tests --no-restore
```

Покрыты: валидация, перенос через месяц/год/високосный день и после простоя, выполнение/отмена, идемпотентность, неизменяемость рекапа, смена серверного дня, сериализация команд, сохранение после открытия базы заново, миграция v3, копирование/восстановление v4 и старой v3, удаление выполненного без потери планов, экспорт, отдельная шкала календаря и отсутствие влияния на часы.

В `src/web`: `npm run lint`, `npm run build`. Для UI нужна отдельная новая база, не личная история:

```powershell
. ./scripts/dotnet.ps1
& $Dotnet run --project tools/WorkLifeBalance.Smoke --no-restore -- --seed .local/todos-check 47837
& $Dotnet publish src/WorkLifeBalance.Host -c Debug --no-restore -r win-x64 --self-contained true -o .artifacts/todos-check
Start-Process .artifacts/todos-check/WorkLifeBalance.Host.exe -ArgumentList '--data-dir', ('"' + (Resolve-Path .local/todos-check).Path + '"') -WindowStyle Hidden
```

Из `src/web`:

```powershell
$env:WLB_TEST_URL='http://127.0.0.1:47837'
npx playwright test
```

Порт должен быть свободен. FixtureData создаёт явно синтетическую историю, завершённую вчера задачу и просроченную открытую. Новые тесты `todos.spec.ts` проверяют интерфейс с настоящим локальным API, планирование, рекап, сохранение после перезагрузки страницы, CSRF/валидацию и скриншоты 1440/390/320 px. Полный набор также проверяет прежние сценарии AFK, исправлений, сайтов и архива. Разрушительные тесты не запускать на личном порту 47831.

Мобильные подписи времени компактные; точная длительность остаётся в подсказке и деталях. Для задач дата выполнения фиксируется при нажатии на сервере; досрочное выполнение запрещено. Перенос открытых задач — проекция даты при чтении, а не ночной таймер, поэтому не требует запущенной программы в полночь.
